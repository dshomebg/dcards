## 1–3. Какво и как

1. **`logUnexpected` в 12 action файла, 5 различни варианта** → `src/lib/log-unexpected.ts`.
   Находка по пътя: `profiles/[id]/actions.ts` логваше `error.cause` на Drizzle (pg `detail`
   = целия ред), а 3 файла — суровия `error` (с `message`). Сега: Drizzle → код + constraint;
   друго → име, код и само редовете `at …` на стека. Тестът доказва, че имейл в `detail`/`message` не излиза.
2. **Препратки към задачи на pagagal** (`ADM-10..27`, `CAT-*`, `SEO-*`) в 17 файла под
   `components/` и `lib/cn.ts` — махнати; препратка към несъществуващо решение в `surface.ts`.
3. **`organization.repository.ts` 267 реда** → клиентски (96) + `organization-admin.repository.ts`.
4. **`theme-contrast.ts` дублира два токена** → тест срещу `src/theme/tokens.css`.
5. **Два `<h1>` в редактора** → `ProfileView nested` рендира името като `h2`.
6. **`vitest.*.ts` извън `tsc`/`eslint`** → в `tsconfig.include` и `lint`; поправени `max-depth`
   (рекурсия в `vitest.setup.db.ts`) и `no-os-command-from-path` (като `scripts/`).
