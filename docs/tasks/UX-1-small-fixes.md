## 1–3. Какво, къде, как

1. **Pro→Free с >6 линка** — записът се отказва без обяснение преди натискане. `LinksFields`
   получава `maxLinks` (от `PLAN_LIMITS[effectivePlan(org)].links` в `page.tsx`) и показва
   `role="alert"` „Премахни N". Сървърният отказ остава непокътнат.
2. **`demo.bg:8080` без схема** се тълкуваше като схема → линкът изчезваше. `hasScheme` в
   `link-href.ts`: `хост:цифри` (+ `/?#` или край) е порт. Резултатът пак е само `https://`.
3. **Дати по UTC** (номер на поръчка, писма, екрани) — `TZ=Europe/Sofia` в runtime на
   `docker/app.Dockerfile` (INF-7). Проверено: `node:24-alpine` с TZ дава 2027 за 31.12 22:30Z.
4. **Цвят `null` показва черно** — `theme-fields.tsx`: бледо (`opacity-40`) + „Не е избран.".
5. **Изтекла сесия при активиране от чипа** → `/login` без `next`. `requireCurrent(next?)`,
   `runCardAction(..., next)`; `activateFromChipAction` подава `/c/{id}`.
6. **Админ поръчки без прелистване** — 50 на страница: `findOrdersForAdmin` с limit/offset,
   `countOrdersForAdmin`, `countOrderPagesForAdmin`; `readPage` (лош вход → 1, над края →
   последната); `UrlPagePager` върху `PagePager`; смяна на филтър маха `page`.
